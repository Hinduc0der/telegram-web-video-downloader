# ТГ: скачать все видео канала

Расширение Chrome, которое скачивает видео из открытого канала или чата в **Telegram Web K**
(`https://web.telegram.org/k/`) — по периодам, с раскладкой по папкам и историей того, что уже скачано.

![иконка](icons/icon128.png)

## Возможности
- Поиск всех видео чата без ручной прокрутки (по желанию — вместе с кружочками-видеосообщениями).
- **Период**: последние 7/30/90 дней, год, всё время или свои даты.
- **Лимит на сессию** — в гигабайтах и/или в файлах; остаток уходит в следующую сессию.
- **Маска имени с папками**: `Telegram/{channel}/{yyyy}-{mm}/{date}_{id}_{name}.{ext}`
  (переменные: `{channel} {yyyy} {mm} {dd} {date} {time} {id} {name} {ext} {caption}`).
- **История по чатам**: сколько скачано и какой период выкачан полностью; кнопка «← Следующий кусок назад».
- **Проверка диска**: удалённые из папки загрузок файлы скачиваются заново (можно выключить).
- Каналы с запретом сохранения контента пропускаются — как и в самом Telegram.
- Windows, macOS, Linux.

## Установка
1. Скачать архив со страницы релизов (или клонировать репозиторий) и распаковать в отдельную папку.
2. `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное» → выбрать папку.
3. Открыть или обновить вкладку `https://web.telegram.org/k/`. Справа внизу появится панель.

**Обязательно:** в `chrome://settings/downloads` выключить «Всегда указывать место для скачивания».
Иначе Chrome спрашивает про каждый файл, папки не создаются и файлы качаются по одному.
Там же можно выбрать, куда идут загрузки, — подпапки создаются внутри неё.

## Как пользоваться
1. Открыть канал, выбрать период и, если нужно, лимит.
2. «Найти» — покажет, сколько файлов и гигабайт войдёт в сессию, сколько уже скачано и чего нет на диске.
3. «Скачать». Порядок — от новых к старым, поэтому прерванная сессия оставляет сплошной выкачанный отрезок.
4. Продолжить: тот же период ещё раз (скачанное пропускается) или «← Следующий кусок назад».

Если переносите скачанное на другой диск — снимите галочку «…если файл ещё на диске»:
для Chrome перенесённый файл выглядит удалённым.

## Как устроено
| Файл | Что делает |
|---|---|
| `content.js` | Панель (в Shadow DOM) и логика. Работает в контексте страницы и вызывает функции самого клиента: `rootScope.managers.appMessagesManager.getHistory` с фильтром видео и `appDownloadManager.downloadToDisc` — родную потоковую загрузку на диск. |
| `bridge.js` | Мост между страницей и фоном расширения (у страницы нет доступа к `chrome.*`). |
| `background.js` | Перехватывает загрузки с web.telegram.org (`chrome.downloads.onDeterminingFilename`) и подставляет путь с папками; хранит историю в `chrome.storage.local`; проверяет, на месте ли файлы. |

Журнал фона: `chrome://extensions` → карточка расширения → «Service worker» → Console, строки `[tgvdl]`.

## Ограничения
- Только версия **K** веб-клиента; в версии A панель лишь предложит переключиться.
- Опирается на внутренние функции Telegram Web K — после обновлений клиента может потребоваться правка.
- Сколько файлов качается одновременно, ограничивает и сам Telegram Web.
- Другие расширения-загрузчики, переименовывающие файлы, могут мешать раскладке по папкам.

Расширение для личного архива: скачивайте только то, к чему у вас есть доступ и что вы вправе сохранять.

Замысел, требования и проверка в деле — владелец репозитория; код написан Claude (Anthropic).
